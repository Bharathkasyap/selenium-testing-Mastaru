# 📚 సామాన్య వివరణ: వెబ్ టేబుల్ డేటా సేకరణ & తనిఖీ

## 🎯 ఈ ప్రాజెక్ట్ ఏమిటి?

వెబ్‌సైట్‌లో ఉన్న టేబుల్స్ (పట్టికలు) నుండి డేటా చదివి, దానిని తనిఖీ చేసే ఆటోమేషన్ టెస్ట్.

---

## 🤔 వెబ్ టేబుల్ అంటే ఏమిటి?

వెబ్‌సైట్‌లో మనం చూసే పట్టికలు (ఉదా: ఉత్పత్తుల జాబితా, కస్టమర్ వివరాలు, ఆర్డర్ చరిత్ర). ఇవి rows (వరుసలు) మరియు columns (నిలువు వరుసలు) కలిగి ఉంటాయి.

### ఉదాహరణ టేబుల్:

| ID | పేరు | స్థితి | తేదీ |
|----|------|--------|------|
| 1 | రాజు | యాక్టివ్ | 01-05-2026 |
| 2 | శ్యామ | ఇనాక్టివ్ | 28-04-2026 |
| 3 | సిరి | పెండింగ్ | 30-04-2026 |

---

## 💡 మనం ఏం చేస్తున్నాం?

### స్టెప్ 1: టేబుల్‌ని కనుగొనడం
```
ఒక గది లో ఒక టేబుల్ (furniture) ఉన్నట్లుగా, 
వెబ్‌పేజీ లో టేబుల్ (HTML element) ని కనుగొంటాం
```

### స్టెప్ 2: హెడర్లు చదవడం
```
టేబుల్ పైన ఉన్న శీర్షికలు (ID, పేరు, స్థితి, తేదీ) చదువుతాం
```

### స్టెప్ 3: ప్రతి వరుస డేటా సేకరించడం
```
టేబుల్‌లో ఉన్న ప్రతి వరుస నుండి:
- మొదటి కాలమ్ నుండి ID
- రెండవ కాలమ్ నుండి పేరు
- మూడవ కాలమ్ నుండి స్థితి
- నాలుగవ కాలమ్ నుండి తేదీ సేకరిస్తాం
```

### స్టెప్ 4: డేటా సరైనదో తనిఖీ చేయడం
```
సేకరించిన డేటా ఆశించిన డేటాతో పోల్చి చూస్తాం
```

## 🎬 వాస్తవ జీవిత ఉదాహరణ

### పరిస్థితి:
మీరు ఆన్‌లైన్ షాపింగ్ వెబ్‌సైట్ టెస్ట్ చేస్తున్నారు

### టాస్క్:
ఆర్డర్ చరిత్ర పేజీలో ఉన్న అన్ని ఆర్డర్ల వివరాలు తనిఖీ చేయండి

### మన ప్రోగ్రామ్ చేసేది:

1. **టేబుల్ కనుగొనడం**
   - "ఆర్డర్ చరిత్ర" టేబుల్‌ని గుర్తించడం

2. **కాలమ్ హెడర్లు తనిఖీ**
   - ఆర్డర్ ID
   - ఉత్పత్తి పేరు
   - ధర
   - తేదీ
   - స్థితి

3. **ప్రతి ఆర్డర్ డేటా చదవడం**
   - మొదటి వరుస: Order #12345, టెలివిజన్, ₹25,000, 01-05-2026, డెలివరీ అయింది
   - రెండవ వరుస: Order #12346, ల్యాప్‌టాప్, ₹45,000, 28-04-2026, షిప్పింగ్‌లో ఉంది
   - ...మరియు మిగిలిన వరుసలు

4. **డేటా ధృవీకరణ**
   - అన్ని ఆర్డర్లు కనిపిస్తున్నాయా?
   - ధరలు సరిగ్గా ఉన్నాయా?
   - తేదీలు సరైన ఫార్మాట్‌లో ఉన్నాయా?
   - స్థితి సరిగ్గా అప్‌డేట్ అయిందా?

## 🔍 టెక్నికల్ కాన్సెప్ట్స్ - సరళంగా

### 1. టేబుల్ లొకేటర్
```
ఒక పుస్తకంలో నిర్దిష్ట పేజీని కనుగొనడం లాగా,
వెబ్‌పేజీలో టేబుల్‌ని కనుగొనే పద్ధతి
```

### 2. Row & Column Navigation
```
చదరంగం బోర్డులో నిర్దిష్ట చతురస్రానికి వెళ్లడం లాగా,
టేబుల్‌లో నిర్దిష్ట వరుస & కాలమ్‌కి వెళ్లడం
```

### 3. Cell Data Extraction
```
నోట్‌బుక్ నుండి వ్రాసిన విషయం చదవడం లాగా,
టేబుల్ cell నుండి టెక్స్ట్ తీయడం
```

### 4. Data Validation
```
పరీక్ష పేపర్‌ని సరిచూడడం లాగా,
సేకరించిన డేటా ఆశించిన విలువలతో సరిపోలిందో తనిఖీ చేయడం
```

## 📝 కోడ్ లాజిక్ - అర్థం చేసుకోవడం

### మనుషుల భాషలో:
```
1. వెబ్‌సైట్‌ని తెరువు
2. "డేటా టేబుల్" అనే పట్టికను కనుగొను
3. టేబుల్‌లో ఎన్ని వరుసలు ఉన్నాయో లెక్కించు
4. ప్రతి వరుస కోసం:
   a. మొదటి కాలమ్ విలువ చదువు
   b. రెండవ కాలమ్ విలువ చదువు
   c. మూడవ కాలమ్ విలువ చదువు
   d. ఈ విలువలను జాబితాలో భద్రపరచు
5. సేకరించిన డేటాను ప్రింట్ చేయి
6. ఆశించిన విలువలతో పోల్చు
```

### Selenium కోడ్‌లో:
```java
// 1. టేబుల్‌ని కనుగొనడం
WebElement table = driver.findElement(By.id("dataTable"));

// 2. అన్ని వరుసలు పొందడం
List<WebElement> rows = table.findElements(By.xpath(".//tbody/tr"));

// 3. ప్రతి వరుస చదవడం
for (WebElement row : rows) {
    List<WebElement> cells = row.findElements(By.tagName("td"));
    
    String id = cells.get(0).getText();      // మొదటి కాలమ్
    String name = cells.get(1).getText();    // రెండవ కాలమ్
    String status = cells.get(2).getText();  // మూడవ కాలమ్
    String date = cells.get(3).getText();    // నాలుగవ కాలమ్
    
    System.out.println(id + " | " + name + " | " + status + " | " + date);
}
```

## 🎪 Advanced Features - సరళంగా

### 1. Pagination (పేజీలు తిప్పడం)
```
పుస్తకంలో పేజీలు తిప్పినట్లు,
టేబుల్‌లో "Next" బటన్ నొక్కి మరిన్ని రికార్డ్‌లు చూడడం
```

### 2. Sorting (క్రమబద్ధీకరణ)
```
పేర్ల జాబితాను A-Z లేదా Z-A క్రమంలో అమర్చినట్లు,
టేబుల్ కాలమ్‌ని క్లిక్ చేసి డేటాను క్రమబద్ధం చేయడం
```

### 3. Filtering (వడపోత)
```
గంజి నుండి బియ్యాన్ని వేరు చేసినట్లు,
టేబుల్‌లో "స్థితి = యాక్టివ్" అని ఫిల్టర్ చేసి సంబంధిత రికార్డ్‌లు మాత్రమే చూడడం
```

### 4. Searching (శోధన)
```
పునుకులో సూది వెతకడం లాగా,
టేబుల్‌లో నిర్దిష్ట పదం లేదా విలువ కోసం శోధించడం
```
