What is this?
-------------
These are 5 real projects where you act as a professional automation tester. Your client gives you a website, and you create tests to make sure it works.

How to use?
-----------
1. Open a capstone project folder
2. Read the PROJECT-BRIEF.md (client request)
3. Read the PROFESSIONAL-APPROACH.md (how to think)
4. Open the Java file and READ it first
5. Run the test using Codespaces or your local setup
6. See if all tests pass
7. Move to next capstone

The 5 Projects
--------------
| Project | Client | Website | Skills | Concepts from Part 2 |
|---------|--------|---------|--------|---------------------|
| Capstone 1 | TechDash Analytics | demoqa.com/login | Login Testing | Locators (ID, Name), Assertions, sendKeys, click |
| Capstone 2 | Student Registry | demoqa.com/automation-practice-form | Form Filling | Dropdowns (Select), Radio Buttons, Checkboxes, Date Picker |
| Capstone 3 | DataCorp Analytics | demoqa.com/webtables | Table Data Extraction | Table Handling (rows, columns), Data Extraction, findElements |
| Capstone 4 | DynamicUI Systems | demoqa.com/dynamic-properties | Dynamic Element Handling | Explicit Waits, Fluent Waits, Expected Conditions |
| Capstone 5 | FrameFlow Agency | demoqa.com/frames | Window & Frame Switching | iFrames, Window Handles, Browser Operations |
