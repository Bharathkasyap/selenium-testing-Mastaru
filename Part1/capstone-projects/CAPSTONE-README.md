# Capstone Projects - Real-World Testing

## What is this?

These are 5 real projects where you act as a professional automation tester. Your client gives you a website, and you create tests to make sure it works.

## How to use?

1. Open a capstone project folder
2. Read the PROJECT-BRIEF.md (client request)
3. Read the PROFESSIONAL-APPROACH.md (how to think)
4. Open the Java file and READ it first
5. Run the test using Codespaces or your local setup
6. See if all tests pass
7. Move to next capstone

## The 5 Projects

| Project | Client | Website | Skills |
|---------|--------|---------|--------|
| Capstone 1 | ShopEasy E-Commerce | practice.expandtesting.com/login | Login Testing |
| Capstone 2 | Student Registry | demoqa.com/automation-practice-form | Form Filling |
| Capstone 3 | Game Online Store | demoqa.com/buttons | Button Testing |
| Capstone 4 | TravelBook Agency | phptravels.org | Travel Booking |
| Capstone 5 | TechStore Online | automationexercise.com | E-Commerce Flow |

## All websites are FREE and WORKING!

Every user gets the SAME output. No confusion. Easy to discuss in WhatsApp group.

## Capstone 1: E-Commerce Login Testing

### Client Brief
Your client ShopEasy E-Commerce is having issues. Users report they cannot login. As an automation expert, test everything.

### What you will learn
- How to think like a professional tester
- What questions to ask the client
- How to design test scenarios
- Complete Java code (ready to run)
- Professional test report

### Website
https://practice.expandtesting.com/login

**Credentials:**
- Valid: Username = `practice`, Password = `SuperSecretPassword!`
- Invalid: Username = `practice`, Password = `WrongPassword`

### Files in this project
- PROJECT-BRIEF.md - Client request
- PROFESSIONAL-APPROACH.md - How experts think
- COMPLETE-SOLUTION.java - Full working Java code
- EXPECTED-OUTPUT.md - What you should see

### క్లయింట్ రిక్వెస్ట్
మీ క్లయింట్ ShopEasy ఇ-కామర్స్‌కి సమస్యలున్నాయి. వినియోగదారులు లాగిన్ చేయలేరని నివేదిస్తారు. ఆటోమేషన్ నిపుణుడిగా, ప్రతిదీ పరీక్షించండి.

### మీరు ఏమి నేర్చుకుంటారు
- ప్రొఫెషనల్ టెస్టర్‌లా ఎలా ఆలోచించాలో
- క్లయింట్‌నే ఏమి ప్రశ్నలు అడగాలో
- టెస్ట్ సన్నివేశాలను ఎలా రూపొందించాలో
- పూర్తి Java కోడ్ (రన్ చేయడానికి సిద్ధం)
- ప్రొఫెషనల్ టెస్ట్ రిపోర్ట్
