# Capstone 1: E-Commerce Login Testing

## PROJECT BRIEF

### Client Name
ShopEasy E-Commerce

### Your Role
Senior Automation Tester (6 years experience)

### Client Request
"We have a new login portal. Users are reporting they cannot login. Please create comprehensive automated tests to verify the login functionality."

### Website to Test
https://practice.expandtesting.com/login

### What You Need to Test
1. Valid login - correct username and password
2. Invalid login - wrong password
3. Invalid login - wrong username
4. Empty username field
5. Empty password field
6. Login button click
7. Success message display
8. Error message display

### Test Data
**Valid Credentials:**
- Username: `practice`
- Password: `SuperSecretPassword!`

**Invalid Credentials:**
- Username: `practice`
- Password: `WrongPassword`

### Expected Outcome
- Valid login should show success page with welcome message
- Invalid login should show error message
- All tests should be executable using the provided Java code

### Deliverables
1. Professional approach document
2. Complete Java automation code
3. Test results report
4. Expected output for each scenario

## Deadline
As a learning project - complete at your own pace
